# Demos

Five runnable scenarios in [`../demos/`](../demos/), each targeting a different
audience. Every scenario loads the same bundled, **offline** AIS fixture
([`demos/data/gulf_scenario.json`](../demos/data/gulf_scenario.json) — 7 vessels,
61 position reports, a synthetic Persian-Gulf picture) and runs the **real public
API**: no live feeds, no API keys, no network.

```bash
PYTHONUTF8=1 python demos/run_all.py            # all five, end to end (exits 0)
PYTHONUTF8=1 python demos/03_port_security.py   # or just one
```

> The fixture is generated by [`scripts/gen_gulf_scenario.py`](../scripts/gen_gulf_scenario.py)
> and committed; demos never regenerate it at runtime. It is hand-tuned so each
> detector path has something to find, with one deliberately clean control vessel
> (`CLEAN TRADER`) that raises no flag — the haystack you filter down from.

## 1. Maritime OSINT sweep — *61 pings → a scored shortlist*
**Audience:** OSINT / intelligence analysts.
Runs the full detector suite and hands back a severity-weighted risk ranking, then
explains why the top vessel (`GREY DAWN`) leads — going dark 30h, loitering,
dark-rendezvous, a speed jump. One vessel raises no flag at all, so the analyst
spends the day on the ranked few.

## 2. Sanctions & compliance — *behaviour + designation → a tiered watchlist*
**Audience:** sanctions / trade-compliance desks.
`locate()` fuses the behavioural detectors with a sanctions screen (MMSI / IMO /
name) and tiers every vessel HIGH / MEDIUM / LOW with a plain-language file note. A
match on the bundled SAMPLE list (same shape as an OFAC SDN export) is a hard
escalation to HIGH regardless of score. Swap in the real list with
`maritimeint import-ofac`.

## 3. Port security & force protection — *where it happened, not just what*
**Audience:** port authorities, maritime security, force protection.
Layers the spatial picture on the behavioural one: zone transits (sanctioned-port
and war-risk boxes), port-call itineraries that touched a risk port, the
dark-rendezvous one tanker hides with another, and a CPA/TCPA close-quarters
standoff breach by a converging unknown contact. CPA/TCPA is separation math —
never an intercept.

## 4. Research export — *one analysis, four standard formats*
**Audience:** researchers and data teams.
Runs the suite once and exports it four ways — GeoJSON (maps), KML (Google Earth),
STIX 2.1 (threat-intel platforms), CSV (notebooks) — validating each is
well-formed, with zero dependencies. STIX ids are deterministic, so re-running is
byte-identical and safe to diff in a pipeline.

## 5. GPS spoofing / EW — *circling tracks & jamming hotspots*
**Audience:** electronic-warfare and GPS-integrity analysts.
Surfaces the two AIS fingerprints of GPS manipulation near conflict zones: a single
hull tracing a tight circle (the "ships circling an airport" artifact), and many
vessels snapped to one synthetic position (a jamming hotspot) — plus the
identity-conflict / static-pin spoofing detector for contrast. Detection over open
broadcast data, not navigation or targeting.

---

Each demo prints clear, narrated output and exits 0, so they double as smoke
tests — [`tests/test_demos.py`](../tests/test_demos.py) runs every scenario and
asserts the headline detections still fire under `pytest`.
